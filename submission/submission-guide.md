# SUBMISSION GUIDE — Womb of Shadows
## What to send, to whom, and in what order

---

## Standard Manuscript Format

All manuscript pages submitted to agents should follow:
- **Font:** Times New Roman, 12pt
- **Spacing:** Double-spaced
- **Margins:** 1 inch on all sides
- **Header:** HART / WOMB OF SHADOWS / [page number] (right-aligned)
- **First page:** Title centered, double-spaced, then "by Roguenealer Stevens", then begin text
- **Paragraphs:** 0.5" first-line indent, no extra space between paragraphs
- **File format:** .docx (never PDF unless specifically requested)

## Direct Submission (No Agent)

### Tor Nightfire (Macmillan)
- **Window:** Typically one week in June. Monitor nightfire.pub and their social media.
- **Portal:** Moksha submissions portal
- **What to send:** Full manuscript + query letter + synopsis
- **Response time:** Up to 9 months
- **Format:** Per their guidelines (usually .docx, standard manuscript format)

### Angry Robot
- **Window:** Periodic open-door submissions (check angryrobotbooks.com/submissions)
- **What to send:** Full manuscript + synopsis + query
- **Format:** .docx, standard manuscript format

### Clash Books
- **Accepts:** Unagented literary horror year-round
- **Portal:** clashbooks.com/submissions
- **What to send:** Query + synopsis + first 3 chapters
- **Response time:** 3-6 months

Use QueryTracker.net (free) to:
- Track all submissions sent, with dates
- Monitor agent response times
- Record any feedback received
- Set follow-up reminders (12 weeks = nudge if no response)

## AI Disclosure Decision Tree

```
Does this agent's agency explicitly prohibit AI-assisted work?
├── YES (e.g., P.S. Literary) → OMIT all AI mention
├── NO / SILENT → OMIT in query, be honest if asked directly
└── Agent has expressed openness to AI → May mention in bio as "co-authored with AI assistance"
```

**Never lie if directly asked.** The career risk of discovery (see: Shy Girl / Hachette cancellation) far outweighs any benefit.

## Pre-Query Checklist

- [ ] Query letter proofread by someone other than the author
- [ ] Synopsis proofread
- [ ] Manuscript formatted in standard submission format
- [ ] Agent-specific guidelines verified (check day of sending)
- [ ] Email address professional (not a gaming handle)
- [ ] Subject line formatted per agent's preference
- [ ] Correct agent name and agency (triple-check personalization)
- [ ] No attachments unless specifically requested (paste in email body)
- [ ] QueryTracker entry created for each submission
